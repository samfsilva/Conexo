# Conexo Game

Um jogo de conexão de palavras similar ao jogo Conexo, onde o objetivo é encontrar grupos de 4 palavras que têm algo em comum.

## Como Jogar

1. Preencha os 16 campos com as palavras que você deseja usar no jogo
2. Clique em "Iniciar Jogo"
3. Selecione 4 palavras que você acredita que formam um grupo
4. Se estiver correto, as palavras serão marcadas com uma cor específica
5. Continue até encontrar todos os 4 grupos

## Características

- Interface moderna e responsiva
- Animações suaves
- Diferentes cores para cada grupo encontrado
- Feedback visual imediato
- Design limpo e intuitivo

## Como Publicar no GitHub Pages

1. Crie um repositório no GitHub
2. Faça o upload dos arquivos para o repositório
3. Vá para as configurações do repositório
4. Na seção "Pages", selecione a branch principal como fonte
5. Clique em "Save"
6. Seu jogo estará disponível em `https://seu-usuario.github.io/nome-do-repositorio`
